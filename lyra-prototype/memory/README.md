# `lyra-prototype/memory/`

This folder is **not** the canonical daily memory home.

Use these rules:

- Daily continuity for the workspace lives in `../memory/`
- Long-term curated memory lives in `../MEMORY.md`
- This local folder is reserved only for:
  - app-specific troubleshooting notes
  - disposable local experiments
  - temporary notes that should not become general workspace continuity

If you are writing a normal day-by-day session log for the human or the wider workspace, write it in `../memory/YYYY-MM-DD.md`, not here.
