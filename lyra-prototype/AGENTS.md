# AGENTS.md

Canonical workspace instructions live at:

- `../AGENTS.md`

If your session starts inside `lyra-prototype`, treat the parent workspace as the real home directory for identity and continuity.

Read in this order:

1. `./SOUL.md`
2. `./USER.md`
3. `../memory/YYYY-MM-DD.md` for today and yesterday
4. In direct chats with the human, also read `./MEMORY.md`

Important memory rule:

- `../memory/` is the canonical daily continuity folder.
- `./memory/` is app-specific notes only.
- Do not write normal day-by-day continuity into `lyra-prototype/memory/` unless the note is specifically about app-local troubleshooting or disposable app-only context.

This local shim exists so agents starting inside the runnable app folder do not mistakenly conclude that the workspace guidance or identity files are missing, and so they do not split daily memory across two folders again.
